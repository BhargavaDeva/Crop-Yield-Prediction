# Crop Yield Prediction

This project uses machine learning to predict crop yields based on various environmental and agricultural factors.

## Dataset
The dataset includes:
- Crop yield data
- Rainfall data
- Pesticides data
- Temperature data

## Requirements
- Python 3.x
- Libraries: numpy, pandas, scikit-learn, seaborn, matplotlib
